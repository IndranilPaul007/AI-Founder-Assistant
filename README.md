# 🚀 AI Startup Copilot

An institutional-grade, AI-powered co-founder portal designed to help early-stage founders transition from raw concepts to execution-ready business strategies, market analysis, financial models, and pitch decks in seconds.

Built for the **NVIDIA AI Hackathon / Innovation Challenge**, leveraging massive open-weights models and secure cloud architecture.

---

## 🌟 Key Features

* **🔒 Secure Supabase Authentication:** Real user registration and login gateway with persistent sessions.
* **🧠 NVIDIA Nemotron-3-Ultra-550B Core:** Powered by high-speed NVIDIA NIM endpoints for deep, factual, data-driven reasoning.
* **📊 6 Comprehensive Founder Protocols:**
  1. **Market Research:** Opportunity scoring, ICP identification, TAM/SAM/SOM sizing in INR (₹), scenario matrices, and 48-hour validation experiments.
  2. **Business Planning:** Auto-generated Lean Business Canvas, unit economics benchmarking, pricing tiers, and a $1B+ scaling roadmap.
  3. **Competitor Intelligence:** Auto-discovery of 20+ global/local competitors with weakness exploitation strategies.
  4. **Fundraising Prep:** Cap table dilution models, valuation caps, term sheet tactics, data room checklists, and hard VC Q&A scripts.
  5. **Task Execution:** Granular 30-day operational sprint roadmaps with tool stack recommendations.
  6. **Strategic Advisor:** An unvarnished, fact-grounded chat advisor leveraging historical startup case studies (Stripe, Razorpay, Swiggy, etc.).
* **📥 Export & Persistence:** Instantly save reports to your Supabase profile, download them as Markdown (`.md`), or export them directly as PowerPoint presentations (`.pptx`).

---

## 🛠️ Tech Stack

* **Frontend & UI:** Python [Streamlit](https://streamlit.io/) with custom high-tech glassmorphism CSS & animated cyberspace grid.
* **AI Model:** `nvidia/nemotron-3-ultra-550b-a55b` via OpenAI SDK & NVIDIA NIM (`https://integrate.api.nvidia.com/v1`).
* **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL & GoTrue Authentication).
* **Document Generation:** `python-pptx` for automated slide deck compilation.
