# AI Startup Copilot (Founder Assistant) 🚀

An institutional-grade, AI-driven co-founder platform built for founders and hackathon evaluations. It leverages **Google Gemini (Gemini Flash)** via the official Google GenAI SDK to provide deep, data-driven startup analysis, financial modeling in Indian Rupees (₹ / INR), competitor benchmarking, fundraising preparation, and operational roadmaps.

---

## ✨ Key Features

- **Secure Authentication Gate:** A polished cinematic founder portal login designed for smooth demo flow.
- **Connected Global Memory:** Startup concepts and names entered in Market Research automatically sync across all operational tabs via session state.
- **Strict Indian Rupee (₹) Standard:** All financial projections, TAM/SAM/SOM, valuation caps, CAC, LTV, and budget allocations are calculated and presented in INR.
- **6 Core Operational Modules:**
  1. **Market Intelligence & Deep Validation:** Opportunity scores, ICP, TAM/SAM/SOM matrix, macro/regulatory trends, scenario analysis, and a 48-hour tactical validation experiment.
  2. **Interactive Lean Canvas & Unicorn Roadmap:** Granular unit economics, cost structures, and an exhaustive 4-phase $1B+ (₹8,300+ Crore) scaling roadmap with failure points and solutions.
  3. **Competitive Intelligence:** Auto-discovers 20+ competitors with weaknesses and exploit strategies.
  4. **Advanced Fundraising Prep:** Valuation caps, cap table dilution models, itemized use of funds, data room checklists, and hardest VC Q&A scripts.
  5. **Task Execution:** 30-day day-by-day operational sprints, tech stacks, and mathematical growth conversion formulas.
  6. **Fact-Grounded Strategic Advisor:** Interactive advisory chat backed by true historical startup case studies (e.g., Razorpay, Swiggy, Stripe) and 24-month second-order effects.

---

## 🔑 Important Note: Google Gemini API Key Required

This application is powered by the **Google GenAI SDK** using **Gemini Flash**. To use the AI analysis engines and interactive strategic advisor:
1. Generate a free API key from [Google AI Studio](https://aistudio.google.com/).
2. Enter your API key directly into the sidebar input field when launching the app.

## 🚀 Local Installation & Running Guide

1. Clone the repository:
   ```bash
   git clone [https://github.com/IndranilPaul007/AI-Founder-Assistant.git](https://github.com/IndranilPaul007/AI-Founder-Assistant.git)
   cd AI-Founder-Assistant
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
